01

어떤 일을 하나요?

기본 측정

중앙 원은 시작 → 일시정지 → 이어서 시작으로 동작합니다.

기록

중간기록 최대 10개, 시작·중지 시각과 시간량의 최근 구간 기록 최대 20개를 제공합니다.

루틴 명령

시작·일시정지·초기화 단축키는 일반 화면 버튼과 별도 중복 호출 규칙을 가집니다.

알림·Now Bar

알림에 측정시간을 표시하고 일시정지 시 멈춘 시간을 유지합니다. 지원 Android에서 Live Update 승격을 요청합니다.

02

처음 사용하기

  1. 게시된 APK의 버전·미완성 표시·검증 범위를 읽고 Android 8.0 이상 기기에 설치합니다.
  2. 앱을 열어 알림 권한을 허용하고 중앙 원으로 시작·일시정지·재개를 시험합니다.
  3. 초기화는 현재 측정과 중간기록을 지웁니다. 이미 저장된 최근 기록과 구분하세요.
  4. 루틴에서는 일반 앱 열기와 개별 스톱워치 명령이 다름을 확인하고 원하는 동작을 선택합니다.
  5. Now Bar가 필요하면 README의 기기별 조건과 별도 ADB 활성화 안내를 먼저 읽으세요. 앱이 해당 설정을 자동 변경하지 않습니다.
03

자주 쓰는 기능

루틴 시작
준비 상태는 새 시작, 실행 중 중복 시작은 0부터 새 측정, 일시정지 상태의 시작은 기존 시간에 이어서 측정합니다.
루틴 일시정지
실행 중이면 구간을 기록하고 멈춥니다. 이미 일시정지 상태에서 다시 누르면 현재 시간·중간기록을 초기화합니다.
중간기록과 최근 기록
10개를 넘는 중간기록으로 기존 항목을 덮지 않습니다. 루틴 중복 시작으로 버린 구간은 최근 기록에 자동 추가하지 않습니다.
Now Bar
기기·One UI·표시 권한에 따라 다릅니다. 비공식 ADB 테스트 플래그는 개발자 기기 설정이며 모든 기기의 표시를 보장하지 않습니다.
04

문제가 생겼을 때

루틴과 중앙 원 동작이 다릅니다
의도된 구분입니다. 루틴 중복 시작·일시정지는 새 시작/초기화 의미가 있으므로 선택한 동작을 확인하세요.
Now Bar가 없습니다
버전·알림 허용·승격 조건과 README의 실제 기기 검증 범위를 확인하세요. 진단값 true가 화면 표시를 보장하지 않습니다.
업데이트 뒤 옛 동작입니다
설치 APK 버전과 선택한 루틴 동작을 확인하세요. 최신 로컬 코드가 GitHub에 게시된 것은 아닐 수 있습니다.
05

데이터와 보안

  • 상태·기록은 기기 내부에 저장합니다. 서버·계정·인터넷 권한이 없습니다.
  • 앱 제거나 데이터 삭제는 기록을 지웁니다. 클라우드 백업·부팅 후 자동 측정 시작은 없습니다.
06

알아두실 제한사항

  • 1.0.10 원격 소스는 루틴 실행 시 메인 화면이 전면에 나타나는 동작입니다.
  • 실제 삼성 루틴과 Now Bar는 Android 에뮬레이터 결과만으로 성공을 판단할 수 없습니다.
  • 기기 재부팅 후에는 마지막 저장 누적시간으로 일시정지 복원합니다. 미저장 구간을 추정하지 않습니다.
  • Now Bar 글자 크기·배치는 One UI가 결정합니다. 앱에서 임의로 최대 크기를 강제하지 않습니다.
07

소스 실행·검증

아래는 문서용 명령 예시입니다. 실제 실행에는 해당 README의 개발 환경·권한·의존성 준비가 필요합니다. 프로젝트 루트에서 사용하며 이 문서를 열기만 해서는 실행되지 않습니다.

.\gradlew.bat testDebugUnitTest lintDebug assembleDebug

Android 프로젝트는 별도 안내가 없으면 JDK 17·Android SDK 설정이 필요합니다. 문서 변경 때문에 앱을 새로 빌드하거나 실제 운영 데이터를 조작하지 않았습니다.
